# Public repository scope

This repository preserves the mod's source history with public GitHub author
identities and generalized personal context. The original development
repository remains private.

The public history omits raw diagnostic logs, assistant-local archive files,
reference-map image files, test save data, and obsolete one-off local helpers.
Technical notes, source attribution, authored map descriptions, project agent
instructions, tests, licenses, and release tooling remain available.

Historical notes may refer to privately archived evidence files or old commit
hashes. They are development records, not proof of the current runtime state.
The public-history preparation retains a private old-to-new commit map.

Users supply their own compatible ROM and saves. Report reproducible gameplay
problems through this repository's Issues page. Beta package publication and
alternate-hardware acceptance are separate from publishing this source.
