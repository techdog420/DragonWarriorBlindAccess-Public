# Handoff Archive

This directory contains historical investigation handoffs from the map-decoding and pathfinding-hardening phase.

These files are preserved as evidence, not active context.

Use them when:
- Investigating why a permanent map-data decision was made
- Reconstructing an old survey or blocker-discovery sequence
- Auditing a historical route, seam, trap cell, or command-timing issue

Do not read the entire archive by default.
