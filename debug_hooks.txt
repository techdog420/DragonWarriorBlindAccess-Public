Dragon Warrior Accessibility Mod — Debug Hooks Cheat Sheet
===========================================================

ENABLE / DISABLE
----------------
In dw_access.ini:
  debug_mode=true          Enable all debug features
  debug_mode=false         Disable (default; all hooks are no-ops)
  debug_log_level=DEBUG    Log everything (default when debug on)
  debug_log_level=INFO     Log INFO and ERROR only
  debug_log_level=ERROR    Log errors only

OUTPUT FILES
------------
  dw_debug.log             Log output (cleared on each script load)
  dw_commands.txt          Write commands here; cleared after reading (~1/sec)
  dw_blocks.log            Legacy optional blocked-move log; one entry per line
                           Format: 0xMM:x,y:dir  (e.g. "0x04:7,5:up")
                           Ignored by default. Set auto_step_record_debug_blocks=true
                           only for local forensic runs.

LOG ENTRY FORMAT
----------------
  [FRAME:nnnnn][LEVEL][state] message
  Example: [FRAME:00450][INFO][battle] EVENT: battle started
  Slow command handlers also emit:
    CMD_TIMING command=pathfind ms=123.456

HOOKS WIRED IN main.lua
-----------------------
  debug_tools.on_menu_open()
    Fires when the command menu opens.
    3 sites: normal open, y<=1 suppressed open, return from STATUS sub-menu.

  debug_tools.on_menu_close()
    Fires when the command menu closes (changes.menu_closed).

  debug_tools.on_dialogue(text)
    Fires whenever new dialogue text is announced.
    3 sites: lower dialogue normal path, lower dialogue y<=3 path, upper window.

  debug_tools.on_battle_start()
    Fires on transition into STATE_BATTLE.
    Auto-calls snapshot() to capture enemy/player state at battle start.

  debug_tools.on_map_change(new_id)
    Fires when nav.check_for_changes() detects a map ID change.

  debug_tools.tick(frame_count, game_state.state)
    Called every frame in the main loop (before FCEU.frameadvance).
    Drives command file polling and log flushing.
    Returns simulated joypad input table or nil.

COMMANDS (write to dw_commands.txt, one per line)
-------------------------------------------------
  log_state                Write full game state snapshot to log

  report_door_state        Write magic-key count and opened-door RAM slots
  report_coords            Write current map/x/y plus raw coordinate-adjacent bytes

  report_movement_state:TAG Same, with TAG included for before/after comparisons
  report_menu_state        Dump command-menu parser/cursor state

                           facing, movement byte, service flag, and raw bytes
  toggle_debug             Flip debug_mode on/off at runtime
  simulate_input:UP        Inject one frame of D-pad Up

  simulate_input:DOWN      Inject one frame of D-pad Down

  trace_input:FRAMES       Same, with frame count clamped to 1..1800
  launcher_probe           Write a launcher readiness marker to dw_debug.log
  launcher_probe:TAG       Same, but include TAG so launchers can wait for an exact line
  ./recover_fceux_input.sh Reset FCEUX stuck-Alt/menu focus from WSL, reset

                           input_status:fceux_recovery
  report_scan_stats        BizHawk only: log PPU read/cache totals and scan profiles
  reset_scan_stats         BizHawk only: reset PPU read/cache totals and scan profiles
  report_title_state       Log title/name-entry cursor state and decoded title rows
  simulate_raw_input:UP    Inject one raw frame of D-pad Up

  add_blocked_edge:MAP,X,Y,DIR Same, but on explicit map

  list_seam_cells          Log current map seam observations with blocked/moved counts
  clear_blocked_tiles      Clear current map runtime blocked tiles
  clear_seam_cells         Clear current map seam observations
  is_blocked_tile:X,Y      Inspect runtime blocked/effective passability state
  dump_blocked_tiles       Dump current map runtime blocked tiles as Lua lines
  sweep_map                Legacy forensic engine-collision sweep of current map.
                           Teleports player to every walkable-looking tile,
                           probes all 4 directions, records hidden engine walls.
                           auto_step is suspended while sweep runs.
                           Outputs ready-to-paste MAP_BLOCKED_CELLS entries.
  stop_sweep               Cancel an active sweep mid-run
  crawl_map_frontier       Start a review-only frontier crawl from the current

  report_merchant_state    Dump merchant/shop detector state, visible decoded rows,

  start_overworld_route    Start manual Travel-filter route guidance to Erdrick's Cave

                           Start the first-dungeon route using the short alias
  start_overworld_route:brecconary
                           Start safety route guidance back to Brecconary
  start_overworld_route:castle

  start_overworld_route:garinham
                           Start route guidance to Garinham / Galenholm

                           Start guide-derived candidate return route guidance

                           replace an active route if another guided Travel
                           destination is selected, or recalculate/status the
                           active route (player hotkey: R)
  route_status             Speak the active overworld route's next waypoint
  route_recalculate        Recalculate the active overworld route's next
                           waypoint from the current world-map position
  recalculate_overworld_route
                           Alias for route_recalculate
  stop_overworld_route     Clear active overworld route guidance
  auto_walk                On the world map, if an overworld route is active,
                           queue one segment to the next waypoint. Stops when
                           the waypoint is reached, movement is blocked, or
                           field movement is interrupted by battle/menu/dialogue.
                           On local maps, auto-walk to the current selected object.
  stop_auto_walk           Cancel the current object auto-walk and release route
                           state without adding movement input.
  ; comment line           Lines starting with ; are ignored

PATHFINDING DEBUG COMMANDS
--------------------------
  debug_pathfind_to:X,Y    Run a detailed current-map route search to X,Y and
                           store the path for trace_path / dump_search_log.
  debug_pathfind_adjacent:X,Y
                           Run a detailed route search to a cell adjacent to
                           X,Y, useful for NPC/object interaction targets.
  debug_pathfind_adjacent_skip_npcs:X,Y
                           Same as debug_pathfind_adjacent, but omits live NPC
                           positions from the blocking table so geometry can
                           be separated from moving or stale NPC clutter.
  trace_path               Log the last stored path coordinates and directions.
  dump_search_log          Log the rejected/visited search details for the last
                           stored path search.

EDGE PROBE COMMANDS
-------------------
  probe_edge:DIR           Probe one step in DIR from current position.
                           Holds raw D-pad input and records whether the engine
                           allowed movement, bypassing auto-step timing.
                           Use after freeze_npcs to avoid NPC interference.
                           DIR: UP / DOWN / LEFT / RIGHT
  probe_edge:X,Y,DIR       Same, but specifies origin explicitly (player must be there)
  stop_probe_edge          Cancel an active probe
  probe_edge_verify:DIR[,N]
                           Repeat a probe from the same origin N times (default 5,
                           max 15), resetting movement state between attempts.
                           Uses raw held input, not auto-step, so collision
                           evidence is not polluted by movement-helper timing.
                           Logs EDGE_VERIFY_* and only reports confirmed_blocked
                           or confirmed_passable when every attempt agrees.
                           Does not inject runtime blockers; use add_blocked_edge
                           after manual review when a blocker should affect paths.
  probe_edge_verify:X,Y,DIR[,N]
                           Same, but specifies origin explicitly. The verifier
                           relocates to that origin and resets between attempts.
  stop_probe_edge_verify   Cancel active repeated edge verification

TELEPORT (DEBUG)
----------------
Writes new player coordinates directly to RAM. Same-map only. Refused during
menus, dialogue, battle, sweeps, active auto-walk, surveys, and edge probes.

  teleport_to:X,Y          Exact teleport; refused if target not walkable
  teleport_to:X,Y,near     Teleport to target, or to the first walkable cardinal/
                           diagonal neighbor (N,E,S,W,NE,SE,SW,NW) if target is blocked
  teleport_to:X,Y,force    Bypass the walkability check (unstick/debug). Can strand
                           the player inside a wall; use with care and save first.
  teleport_selected        Teleport to the currently selected object, using the
                           same player-facing landing/facing path as Shift+Enter
  teleport_selected:MODE   MODE is exact, north, south, west, or east
                           NPC targets are briefly held for TALK, face the
                           target after landing, and log TELEPORT_SCAN_GRACE /
                           TELEPORT_SELECTED_TIMING for lag checks.
  teleport_landmark:NAME   Same-map debug teleport to a named overworld Travel
                           landmark. World map only. Accepts exact names, object
                           ids, and unique prefixes; alias: teleport_overworld.

MAP SURVEY COMMANDS
-------------------
Automated adjacency survey: auto-walks to every object on the map to probe
directional passability. Freeze NPCs first for clean results.

  report_survey_start      Preflight: reports reachable area, open exits, and whether
                           the current start is isolated. Does not launch a survey.
  report_survey_start:retry_failed  Same preflight using the failed-target set.
  report_survey_start:park_npcs  Same preflight, annotated for parked-NPC survey mode.
  survey_objects           Survey all objects on the current map.
  survey_objects:retry_failed  Re-run only the targets that failed last time.
  survey_objects:park_npcs  Survey with non-target NPCs parked off-screen for the run.
  survey_objects:retry_failed,park_npcs  Retry failed targets with parked-NPC mode.
  survey_map               Alias for survey_objects.
  survey_target:NAME       Survey a single named target (partial name match).
  survey_target:NAME,park_npcs  Single-target survey with parked-NPC mode.
  stop_survey              Cancel the active survey run.
  report_survey_findings   Summary: failed target count + strong candidate count.
  report_survey_findings:MAP_ID  Same for an explicit map ID.
  report_failed_targets    Log all targets that failed in the last survey.
  report_failed_targets:MAP_ID  Same for an explicit map.
  report_strong_candidates Log high-confidence directional-block candidates.
  report_strong_candidates:MAP_ID  Same for an explicit map.
  report_candidate_suggestions  Log suggested MAP_DIRECTIONAL_BLOCKS entries to try.
  report_candidate_suggestions:MAP_ID  Same for an explicit map.
  list_blocked_candidates  List recorded blocked-candidate cells with counts.
  list_blocked_candidates:MAP_ID  Same for an explicit map.
  dump_survey_report       Full per-target result log for the last survey run.
  dump_survey_report:MAP_ID  Same for an explicit map.
  export_blocked_candidates       Export only pasteable confirmed candidates; skips diagnostics.
  export_blocked_candidates:MAP_ID  Same for an explicit map.
  export_directional_candidates   Export as MAP_DIRECTIONAL_BLOCKS Lua lines.
  export_directional_candidates:MAP_ID  Same for an explicit map.
  reset_survey_candidates  Clear all candidate data for the current map.
  reset_survey_candidates:MAP_ID  Clear candidate data for an explicit map.

BLOCK DETECTION WORKFLOW
-------------------------
  Passive debug logging (legacy/forensic only):
    1. Set debug_mode=true in dw_access.ini
    2. Set auto_step_record_debug_blocks=true only for the local run
    3. Play normally — blocked steps append to dw_blocks.log
    4. Treat this output as review material, not map truth
    5. Turn auto_step_record_debug_blocks back off afterward

  Manual promotion:
    1. Verify the suspect cell/edge on the correct map
    2. Prefer directional evidence such as probe_edge_verify:X,Y,DIR,N
    3. Use add_blocked_edge:X,Y,DIR for a deliberate runtime edge blocker
    4. Use add_blocked_tile:X,Y only for a deliberate full-cell runtime block
    5. Patch map_reader.lua only after map-scoped evidence is strong

  Export review:
    1. Set debug_mode=true in dw_access.ini
    2. echo export_blocks > dw_commands.txt
    3. Check dw_debug.log for MAP_BLOCKED_CELLS Lua entries to review

  Active (exhaustive per-map sweep):
    1. Set debug_mode=true in dw_access.ini
    2. Navigate into the map you want to sweep (e.g. Tantegel Castle)
    3. echo sweep_map > dw_commands.txt
    4. Wait for sweep to finish (watch dw_debug.log; "SWEEP COMPLETE" appears)
    5. Review MAP_BLOCKED_CELLS entries from dw_debug.log before promotion
    6. Reload script to apply

  NOTE: sweep_map is safe for town/castle maps (no random encounters).
        Use with caution in dungeons — random battles may interrupt the sweep.

  Survey workflow (preferred for new maps):
    1. freeze_npcs
    2. report_survey_start          (verify start is not isolated)
    3. survey_objects
    4. Wait for "Survey complete" speech
    5. report_survey_findings        (overview of results)
    6. dump_survey_report            (full per-target details if needed)
    7. export_directional_candidates (review output before map_reader.lua patch)
    8. unfreeze_npcs

CALLING HOOKS FROM LUA (manual use in debug sessions)
------------------------------------------------------
  debug_tools.log(debug_tools.ERROR, "message")
  debug_tools.log(debug_tools.INFO,  "message")
  debug_tools.log(debug_tools.DEBUG, "message")
  debug_tools.error("message")    -- shorthand for ERROR
  debug_tools.info("message")     -- shorthand for INFO
  debug_tools.debug("message")    -- shorthand for DEBUG
  debug_tools.snapshot()          -- log full state snapshot now
  debug_tools.shutdown()          -- flush log before exit

QUICK SHELL USAGE
-----------------
  PowerShell / Codex:
    ./dw_commands.ps1 log_state
    ./dw_commands.ps1 sweep_map
    ./dw_commands.ps1 export_blocks
    ./dw_commands.ps1 stop_sweep
    ./dw_commands.ps1 freeze_npcs report_survey_start survey_objects
    ./dw_commands.ps1 stop_survey
    ./dw_commands.ps1 report_survey_findings
    ./dw_commands.ps1 dump_survey_report export_directional_candidates
    ./dw_commands.ps1 probe_edge:RIGHT

  Bash / WSL / cmd with bash:
    ./dw_commands.sh log_state
    ./dw_commands.sh sweep_map
    ./dw_commands.sh export_blocks
    ./dw_commands.sh stop_sweep
    ./dw_commands.sh freeze_npcs report_survey_start survey_objects
    ./dw_commands.sh stop_survey
    ./dw_commands.sh report_survey_findings
    ./dw_commands.sh dump_survey_report export_directional_candidates
    ./dw_commands.sh probe_edge:RIGHT
  tail -f dw_debug.log
  tail -f dw_blocks.log   (only when auto_step_record_debug_blocks=true)

Deterministic command confirmation:
  ./dw_commands.sh --replace --wait "LAUNCHER_PROBE: ready" launcher_probe:ready report_position
  ./dw_commands.sh --replace --wait-ready ready report_position
  ./dw_commands.ps1 --replace --wait "POSITION:" report_position
  ./dw_commands.ps1 --replace --wait-ready ready report_position
  Add --timeout SECONDS to override the default 10 second wait.
  Add --require-live SECONDS to fail before queueing if dw_debug.log is missing or older than that threshold.
  Add --json to print machine-readable status for automated harnesses.
  --wait only matches dw_debug.log lines written after the command is queued, so stale log entries do not create false positives.
  --wait-ready TAG queues launcher_probe:TAG and waits for the fresh LAUNCHER_PROBE marker.

Reload / restart protocol:
  reload_config is only for dw_access.ini changes.
  For Lua source changes, BizHawk's file-change reload can pick up touch main.lua while the Lua loop is alive.
  Always follow a source reload trigger with a fresh launcher_probe:TAG, --wait-ready TAG, or another fresh state probe.
  If the probe times out, dw_debug.log is stale, or dw_script_error.log changed, relaunch with ./launch_dw.sh instead of queueing more commands.

Export safety note:
  Treat aggregate map/block exports as review material unless the command name or surrounding log evidence identifies confirmed candidates. Prefer report_candidate_suggestions or export_directional_candidates for survey-derived directional door/wall findings.
